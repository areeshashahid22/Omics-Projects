# 🧬 Omics Projects

A collection of bioinformatics projects completed during the **Omics Nexus Summer School 2026**.

---

## 🔬 Modules Overview

**Module 1 — Foundations**
Core bioinformatics tools: Python, R, Linux, and Bash scripting.

**Module 2 — Transcriptomics & ML**
scRNA-seq pipeline for DEG identification and patient sample classification.

**Module 3 — AI Protein Design**
End-to-end peptide binder design against the Nipah virus receptor-binding protein using ESMFold, fpocket, RFdiffusion, ProteinMPNN, and AlphaFold2 validation.
